# Banks

Генератор писем для рассылки по банкам. Текст письма набирается в окне один раз.
Получатели читаются из книги Excel: каждый лист — отдельная рассылка (имя листа —
банк, например «Банк 1»), в колонке A этого листа — его адреса.

Каждому адресу уходит своё письмо Outlook. Адреса не собираются в одно письмо
полями To, Cc или Bcc, поэтому списки остаются раздельными.

Пароли и настройки SMTP приложение не хранит. Письмо отправляет установленный
Outlook, в котором уже выполнен вход.

## Что нужно

- Windows
- Python 3.10 или новее
- Microsoft Excel (книга открывается через Excel)
- Microsoft Outlook, установленный и с выполненным входом в почту

Книга не должна запрашивать пароль при открытии.

## Установка

1. Установите Python с [python.org](https://www.python.org/downloads/windows/).
   В установщике включите «Add python.exe to PATH».
2. Откройте командную строку в папке проекта и выполните:

```
pip install -r requirements.txt
```

Если команда `python` или `pip` не находится, используйте `py` и `py -m pip`.

## Запуск

```
python app.py
```

Команда `pythonw app.py` открывает только окно, без чёрной консоли.

## Где прописать путь к Excel

Книга в окне не выбирается. Путь задаётся в файле `app.py`, константа `WORKBOOK_PATH` (строка 4). Над ней комментарий «сюда пропиши свой путь». Замените пример на свой путь к файлу `.xlsx`, сохраните файл и запустите приложение снова. Листы откроются сами.

```python
# сюда пропиши свой путь
WORKBOOK_PATH = r"C:\путь\к\файлу\banks.xlsx"
```

Пример книги — `banks.xlsx` в корне репозитория; свой путь всё равно прописывается в `WORKBOOK_PATH` в `app.py`.

## Как пользоваться

1. Пропишите путь к книге в `WORKBOOK_PATH`, как в пункте выше.
2. Запустите приложение. Листы и число адресов появятся сами.
3. Оставьте отмеченными нужные банки.
4. Введите тему и текст. Они одинаковые для всех получателей.
5. При необходимости укажите файл вложения.
6. Нажмите «Отправить». В подтверждении будет число отдельных писем.

Если файла по этому пути нет, окно напишет, где именно искало. После правки книги нажмите «Обновить листы»: отправляется тот список, который показан в окне.

Перед отправкой книга и вложение копируются в папку `archive` рядом с `app.py`,
во вложенную папку с датой и временем. Если Outlook недоступен, письма не
отправляются и в журнале будет текст ошибки.

## Формат книги

- Один лист — один банк. Имя листа видно в списке.
- Адреса только в колонке A, по одному в ячейке, без имени и угловых скобок.
- Пустые ячейки пропускаются.
- Если в A1 не адрес, а заголовок («email», «почта» и тому подобное), он пропускается.
- Ячейка, не похожая на адрес, пропускается, и это пишется в журнал.
- Повтор адреса на том же листе отбрасывается без учёта регистра. Тот же адрес на другом листе
  получит отдельное письмо: листы — разные рассылки.

Пример:

```
Лист «Банк 1»          Лист «Банк 2»
A1  почта              A1  petr@example.com
A2  ivan@example.com   A2  petr@example.com
A3  maria@example.com
```

С листа «Банк 1» уйдут два письма, с листа «Банк 2» — одно (повтор в A2 снят).

## Журнал

Для каждого адреса строка вида: лист, адрес, результат («отправлено» или текст ошибки).
Пропущенные ячейки помечаются как заголовок, неверный адрес или повтор.

## Если что-то не открывается

- Окно пишет «Файл книги не найден» и показывает путь: поправьте `WORKBOOK_PATH` в `app.py` (строка 4).
- Окно пишет, что нет pywin32: ещё раз выполните `pip install -r requirements.txt`
  в этой папке. Если модуль установлен, но не находится, выполните
  `py -m pywin32_postinstall -install`.
- Окно пишет, что Excel недоступен: установите Microsoft Excel.
- Окно пишет, что Outlook недоступен: откройте Outlook и проверьте вход в почту.
- Outlook или антивирус спрашивает разрешение на отправку: его нужно подтвердить.
  Отказ попадёт в журнал напротив адреса.
